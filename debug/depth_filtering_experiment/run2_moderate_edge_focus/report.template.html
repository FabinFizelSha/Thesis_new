__EXAMPLES__

Caveats

Edge sharpness is a proxy, not ground truth. Canny-detected RGB edges include some texture-only edges (not real depth boundaries), which dilutes rather than biases the signal — there's no independent higher-precision depth reference for this bag to validate against directly.

Different bag from Run 1, so the two reports' absolute numbers (coverage %, roughness mm) are not a strict controlled A/B of aggressive-vs-moderate on identical data — a true head-to-head would rerun both parameter sets on the same bag. This run is the direct answer to "what does moderate get us," not a rerun of run 1 with one setting changed.

Coarse (9×9) roughness was not recomputed this run — it was the most expensive part of Run 1's analysis, and this run's ask was specifically about edges, not re-litigating flat-region noise at multiple scales.
