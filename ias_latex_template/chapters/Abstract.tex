\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

{\small Conventional risk assessment mechanisms are limited when the control strategy or operating environment of an autonomous system changes after deployment. This limitation is particularly relevant for systems operating in dynamic environments or modified through adaptive software components and over-the-air updates.\par}

{\small This thesis extends the framework for online risk-annotated scene graph generation presented by Andr\'e Schiel in the master's thesis \emph{Online Risk-Annotated Scene Graphs for Autonomous Systems}~\cite{previous_rsg_thesis} into a spatial scene graph that supports dynamic risk assessment in near real time. The scene graph represents objects together with their spatial context, semantic labels and risk-relevant object descriptions generated by a vision-language model, and confidence values for each object's identity, its mobility and whether it is still at its last observed position. The framework is built as a modular ROS~2 system, which supports portability and integration with robotic platforms, and it builds on the Hydra spatial perception system to support large environments. Objects are segmented with NanoSAM and kept as persistent tracks, so that each graph node represents one physical object across observations and sessions.\par}

{\small Development and optimisation were carried out on an NVIDIA Jetson AGX Orin using the office scene of the simulated uHumans2 dataset, and the system was subsequently ported to an NVIDIA Jetson AGX Thor. NanoSAM was more accurate than SAM with a ViT-B encoder and about ten times faster. When the pipeline resumed in a previously mapped environment, 97.5\,\% of the re-encountered objects were re-identified. Qwen3.5-4B combined with an optimised prompt was selected for object labelling, reaching an accuracy of 88\,\% on 50 manually verified object crops. Additional tests on the uHumans2 apartment scene and on the office scene of the real-world OpenLORIS-Scene dataset demonstrate portability across environments and across simulated and real sensor data. On the Jetson AGX Thor, the pipeline processes about 4.8 frames per second on the uHumans2 office sequence in its final configuration, twice the rate of the Jetson AGX Orin, and each processed frame reaches the spatial scene graph within approximately 0.3\,s on average. Geometry and object tracking keep pace with this rate, whereas semantic labelling lags on a first visit and catches up once objects are revisited. The risk-annotated scene graph is thereby available as environmental context during system operation.\par}

\vfill
{\small \noindent\textbf{Keywords:} dynamic risk assessment, risk-annotated scene graph, ROS~2, Hydra, NanoSAM, persistent object tracking, uncertainty-aware object representation, vision-language model.\par}
